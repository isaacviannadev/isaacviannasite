# Portfolio refresh

## Direction
Preserve Isaac’s coral accent, dark canvas, Bricolage Grotesque and Instrument Serif. The work and its engineering decisions should carry the story.

- Palette: canvas #0b0a09; raised surface #100f0d; text #f3efe7; supporting text #aaa69d; coral #f94b52; pale coral #fb8a8f.
- Type: Bricolage for product narrative and display, Instrument Serif for the existing project wordmarks, Space Mono only for compact metadata.
- Layout: identity + architectural headline beside an existing Vodafone project preview; projects immediately after the hero; then about, expertise, DIV and contact. Horizontal navigation remains on roomy desktops; short desktop windows keep horizontal navigation with compact, scrollable panels; touch and reduced motion use native vertical reading.
- Principles: lead with real work, explain individual contribution, give direct paths to projects/contact, keep the bilingual experience complete. No new performance or business metrics.

## Review
A generic manifesto and rotating role list delayed access to the work. Replace these with a specific frontend narrative and a project preview. Retain the existing visual identity instead of introducing a new template. Remove the forced loading sequence, optimize portrait/favicon assets, and make anchor navigation work with keyboard, hashes and browser history.
